# Custom components register

Components and patterns created for this prototype that are not part of the TNA Design System or GOV.UK Frontend. Each one is isolated so it can be reviewed on its own: markup in `app/views/components/<name>/`, styles in `app/assets/sass/components/_<name>.scss`, class names prefixed `proto-`.

| Component | What it is for | Existing components considered | Source | Used in | Status |
|---|---|---|---|---|---|
| Catalogue reference (`protoCatalogueReference`) | Shows a catalogue reference such as "PROB 1/4" in a monospace, tinted, bordered inline box so it reads as an identifier. | Plain `<strong>` (no identifier styling). Inline `<code>` (pink text and a different font; also the wrong meaning, as a reference is not code). `tnaTags` (reads as a link or filter). | Mirrors the `.reference` class on the beta catalogue record page, which is not in the design system. Values copied from beta's CSS. | `app/views/test-journey/record.html` | Awaiting review |
| Catalogue accordion (`protoCatalogueAccordion`) | Expandable sections at the bottom of a catalogue record page ("How to order it", "Series information", "Catalogue hierarchy"), styled as separate tinted blocks with larger headings. | `tnaAccordion` as it comes: smaller headings (18px against 22px), keylines between items and no background, so it does not match beta. `tnaDetails`: a different pattern, one item at a time with a link-style summary. | Mirrors `etna-accordion` on the beta catalogue record page, which is itself a restyled copy of the design system accordion. This version reuses the TNA accordion markup and JavaScript and overrides styles only, scoped to `.proto-catalogue-accordion`. Values copied from beta's CSS. | `app/views/test-journey/record.html` | Awaiting review |
| About these records (`protoAboutTheseRecords`) | In-context help on a catalogue record page. Says which series the record is in, gives two or three short facts about the records in that series (what they are, the thing people misread, how to see them), and lists whole guides that use the records without excerpting them. One note is written per series and shown on every record in it. | `tna-aside` on its own (used as the base; needs structure for the points and guide list). `tnaDetails` or `tnaAccordion` (would hide the help by default, which defeats the point of testing whether it is noticed). `tnaWarning` (wrong meaning). | New pattern for this alpha; not on the beta site. Built on `tna-aside`, the TNA grid and the catalogue reference component, with a small amount of custom CSS (accent left edge, spacing). | Not currently used. Removed from `app/views/test-journey/record.html` on 7 October 2026 in favour of a simple signpost panel. | Parked |
